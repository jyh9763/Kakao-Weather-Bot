# 자동 날씨 정보 알려주는 봇

오늘의 기상 데이터 받아서 카카오톡으로 날씨 알려주는 봇입니다.

- python 사용
- 공공데이터포털 - 기상청 단기예보 조회서비스 API 사용
- 카카오 API 사용
- Copilot 바이브 코딩
- - -
# 프로젝트 계획서

카카오톡 메시지를 통해 매일 특정 시간에 오늘의 날씨를 알려주는 Python 프로그램을 개발합니다.

## 주요 기능
1. 날씨 정보 가져오기: 기상청 API를 사용해 오늘의 날씨 정보를 가져오기.
2. 카카오톡 메시지 전송: 카카오톡 메시지 API를 사용해 날씨 정보를 전송.
3. 자동 실행: 프로그램이 매일 특정 시간에 실행되도록 스케줄링.

## 기술 스택
언어: Python
- 라이브러리:
  - requests (API 호출)
  - json (데이터 처리)
  - python-dotenv (환경 변수 불러오기)

## 외부 API:
  - 기상청 단기예보 조회서비스 API (날씨 정보)
  - KakaoTalk 메시지 API (카카오톡 메시지 전송)

## 작업 단계
기상청 단기예보 조회서비스 API 키 발급 및 테스트.
카카오톡 메시지 API 설정 및 인증 토큰 발급.
날씨 정보 가져오는 기능 구현.
카카오톡 메시지 전송 기능 구현.
프로그램 테스트 및 디버깅.
